# SciViz 使用引导手册

这份手册写给第一次使用 SciViz 的研究者，也可以作为小功能的速查表。它按当前界面的实际行为编写，更新于 **2026-10-02**。安装步骤见 [README](../README.md#快速开始浏览器画布)，设计与开发资料见 [文档索引](./README.md)。

SciViz 希望让实验过程更容易看懂：每个块代表一个步骤，端口说明它接收什么、产出什么，连线表示数据怎样流动。人可以自己搭建，也可以让 Agent 操作同一份工程，再沿着画布检查和接手。

这是一个通过 **vibe coding（与 AI 协作编程）** 逐步构建、仍在完善的早期项目。我自己也在研究中使用它；遇到不顺手或有问题的地方，欢迎通过 [Issues](https://github.com/ShangYangXU/sciviz-web/issues) 告诉我。

## 1. 五分钟看见第一张图

先按 [README 的快速开始](../README.md#快速开始浏览器画布) 启动页面。下面这个例子只用合成数据，不需要模型 API key、GPU 或本地宿主。

1. 点击顶栏 **导入数据**，选择 [examples/quickstart.csv](../examples/quickstart.csv)。
2. 确认 `x`、`y` 两列都已启用，点击 **完成**。
3. 点击 **打开工程**，选择 [examples/quickstart.sciviz](../examples/quickstart.sciviz)。
4. 如果数据源没有自动绑定，选中 **合成数据**，在右侧 **节点参数 → 数据集** 中选择 `quickstart`。
5. 等待引擎加载和计算。画布上应出现下面的链路：

```text
合成数据 → 原始数值 → y = 2x + 1
```

**核对结果：**预览中有 5 行数据，`x` 为 `0, 1, 2, 3, 4`，`y` 为 `1, 3, 5, 7, 9`；图表是一条直线。

接着试三个小操作：

- 选中图表，在右侧切换图表类型，观察节点里的图怎样变化。
- 点击图表上的 **贴到画布**，留下这次结果的图片快照。
- 点击顶栏 **运行**，再打开右侧 **资产库**，查看本次汇总和来源节点。

最后点击 **保存工程** 保存自己的副本。后面的章节可以按需要查阅。

## 2. 认识工作区

| 位置 | 用来做什么 |
|---|---|
| 顶栏「画布」 | 搭建步骤、查看接口和运行结果 |
| 顶栏「AI 工作区」 | 与可以操作工程的 Agent 对话，管理项目对话 |
| 顶栏文件按钮 | 导入数据、打开或保存工程、导入或导出 YAML |
| 左侧节点库 | 搜索节点，点击添加或拖到指定位置，收藏常用节点 |
| 中央画布 | 连线、调参数、看图，摆放图片和其他批注 |
| 右侧「节点参数」 | 编辑所选节点的名称、代码、参数及说明 |
| 右侧「资产库」 | 查看本次运行汇总出的表、图和指标等资产 |
| 右侧「实验笔记」 | 记录实验判断、图片和节点引用 |
| 「项目报告」 | 打开浮动报告窗口，查看、编辑和下载报告 |

右栏可以收起，为画布留出空间。收起后点击侧边的标签，可以直接打开对应面板。切换到 AI 工作区后，仍然操作同一个工程。

顶栏还会显示执行引擎状态。普通数据处理可以在浏览器里计算；检测到本地宿主后会优先使用宿主。标有 **需宿主** 的模型和训练节点，需要先启动本地宿主，不能只靠浏览器运行。

## 3. 导入数据、拆列与拼表

### 3.1 导入后先看一眼数据

点击 **导入数据**，拖入或选择本地 CSV。解析器支持 UTF-8 / GBK，并自动识别分隔符、表头、时间列与采样步长。

导入窗口会列出行数、时间范围、采样步长和各列统计。可以用最小值、最大值、均值和零值占比做一次快速核对。零值很多只是一个提示，软件不会因此自动删行或清洗数据。

列名前的复选框控制是否启用该列。关闭的特征列不参与下游计算；识别出的时间列会标为 **时间轴**，与普通特征分开处理。

可以导入多个数据集，在窗口中切换查看。数据加入工作区后，还要在画布上的 **数据源** 节点中明确选择它。导入成功不等于每个数据源都已经绑定。

### 3.2 数据源给出整表，拆列给出单列

常用连接方式是：

```text
数据源（整表） → 函数 / 图表 / 数据预览
数据源（整表） → 拆列 → 各个单列输出
```

**拆列** 会把上游表的各列变成单独的输出端口。留空表示拆出上游的全部特征列；端口可能要等上游计算完成后才出现。

只想取一部分时，在 **只拆这些特征（索引）** 中填写 `1,3` 等索引。索引从 **1** 开始，时间列不计入特征索引。先核对上游列顺序，再填写索引。

### 3.3 把几列重新拼起来

用 **列拼表** 接收多路表或单列结果，再交给后续函数、图表或训练步骤。它适合把拆出的特征重新组合，也适合把函数输出的几张表按列拼在一起。

拼好后接一个 **数据预览**，检查实际行数、列名和数值；不要仅凭连线看起来正确就认为列已经对齐。

## 4. 画布操作与快捷键

### 4.1 摆放和选择

- **添加节点：**点击节点库卡片，或拖到画布上的目标位置。
- **移动节点：**拖动卡片空白处。输入框、按钮和端口保留各自的操作。
- **移动视野：**拖动画布空白处，或使用滚轮平移；按住空格可临时进入平移操作。
- **框选多个内容：**按住 `Shift`，在空白处拖出选框。
- **逐个多选：**按住 `Ctrl`（macOS 为 `Cmd`）点击节点或批注。
- **缩放和找回内容：**使用画布的缩放、适应视野按钮；小地图也可以帮助定位。

点中一个计算节点时，相关上下游链路会突出显示，方便追踪“它从哪里来、又送到哪里去”。点击空白处或按 `Esc` 可以退出链路聚焦。

### 4.2 快捷键速查

| 操作 | Windows / Linux | macOS |
|---|---|---|
| 多选 | `Ctrl` + 点击 | `Cmd` + 点击 |
| 框选 | `Shift` + 拖动空白 | 同左 |
| 删除选中的节点、连线或批注 | `Delete` / `Backspace` | 同左 |
| 撤回一步 | `Ctrl+Z` | `Cmd+Z` |
| 重做一步 | `Ctrl+Y` 或 `Ctrl+Shift+Z` | `Cmd+Y` 或 `Cmd+Shift+Z` |
| 复制选中的内容 | `Ctrl+C` | `Cmd+C` |
| 粘贴 | `Ctrl+V` | `Cmd+V` |
| 临时平移 | 按住空格 | 同左 |

画布上还有撤回和重做按钮。焦点在代码、文本输入框或表格单元格里时，编辑操作交给当前输入框；先点回画布再使用画布快捷键。

复制一组选中内容时，会复制其中的节点、批注和内部连线，粘贴后生成新的节点身份。与未选中节点相连的外部线不会一起带过去，复制后请检查入口和出口。

### 4.3 标准与紧凑显示

画布工具栏的 **标准 / 紧凑** 可以切换卡片密度。标准模式显示参数和预览，紧凑模式主要保留名称与端口，适合观察大图结构。

紧凑模式下仍可选中节点，在右侧查看和编辑参数。这只是显示偏好，不会改变计算逻辑。

## 5. 接口、参数与 Python 函数

### 5.1 先认接口，再拉线

从上游输出端口拖到下游输入端口。接口检查会拒绝类型不兼容、已占用的单输入端口，以及会形成循环的连接，并给出原因。

被拒绝时，先读提示，再检查端口的名字和类型。例如图表需要数据表，训练节点需要模型定义和训练数据；模型对象不能直接当成数据表接入。

### 5.2 参数手填与接线

选中节点，在右侧 **节点参数** 中修改。较长的 **参数**、**节点信息** 区域可以折叠；**恢复默认** 用于恢复该节点参数。

函数的默认参数可以直接填写。需要让它由另一个节点提供时，点击 **需要接线？显示接线口**，再接入上游结果。接线后该参数由上游提供；断开后恢复使用本地设置或默认值。未接线时也可以 **收起接线口**，减少画布上的端口数量。

英文变量旁的中文说明可以点击修改。例如给 `work_segment` 写上“工作段编号”，便于自己和接手的人理解。中文说明帮助阅读，不会改动 Python 变量名。

### 5.3 写一个小函数

添加 **函数** 节点，在右侧填写代码。以下示例可以接入快速开始中的整表，把 `y` 列乘上一个系数：

```python
def run(data, factor=2.0):
    result = data.copy()
    result["y"] = result["y"] * factor
    return {"result": result}
```

界面会从代码读取接口：

- `data` 没有默认值，需要接入数据。
- `factor` 有默认值，可以在参数区修改，也可以显示端口后接线。
- 返回字典中的 `result` 成为输出端口，可以接 **数据预览** 或 **图表**。

用示例数据和默认系数运行后，`y` 应为 `2, 6, 10, 14, 18`。把 `factor` 改为 `1.0`，应该恢复原来的数值。这可以帮助确认你修改的是正确步骤。

代码改了形参或返回字典的键，端口也会改变，随后检查原有连线。建议使用清晰、固定的返回键，让接口容易识别。

普通函数可在浏览器 Python 或本地宿主执行。浏览器能用的库由随应用提供的科学计算包决定；需要 `torch` 等宿主依赖的代码，应连接本地宿主。软件不会自动把所有 Python 依赖安装到浏览器里。

## 6. 查看结果与管理图表

### 6.1 在中间步骤插入数据预览

想知道某一步到底算出了什么，把它的输出接到 **数据预览**。它可以显示表格前几行及指标值；预览区会说明结果来自哪个节点。

**行数** 参数只控制显示多少行，不会截断传给下游的整表。因此可以把预览插在数据链路中：

```text
处理函数 → 数据预览 → 图表
```

预览显示“重算中”时，画面可能暂时保留上次结果；等重算完成后再判断本次输出。上游失败时，先处理上游错误；当前预览暂不支持的输出类型会明确提示。

### 6.2 普通图表跟着实际输入变化

添加 **图表**，接入上游数据表，再选择图表类型、X / Y 字段、颜色与配色等选项。也可以使用 **概率密度图** 查看数值分布。

图表画的是它实际接到的那一步数据。接入处理后的表时，看到的是处理后的结果。尚未接线或上游没有输出时，先完成数据连接。

普通计算和图表会随输入、参数变化自动更新。顶栏 **运行** 会把当前计算结果汇总到资产库；看一张图的变化不必每次都点击它。

大表可能经过抽稀后显示。预览和资产详情会提示图上的点数及原表规模；图上点数不代表原始数据只有这些行。

### 6.3 用 Matplotlib 自定义图表

需要自己控制绘图代码时，添加 **自定义图表**。例如：

```python
def plot(data):
    import matplotlib.pyplot as plt

    fig, ax = plt.subplots(figsize=(6.4, 4.2), constrained_layout=True)
    ax.plot(data["x"], data["y"], marker="o")
    ax.set_xlabel("x")
    ax.set_ylabel("y")
    ax.grid(True, alpha=0.25)
    return {"figure": fig}
```

把快速开始的数据表接到 `data`，图片会显示在该节点里。需要返回 Matplotlib 的 `Figure`，只调用 `plt.show()` 不会形成这个输出接口。

### 6.4 留下一张图的快照

图表节点、训练曲线和资产库图表详情中的 **贴到画布**，可以把当前图变成图片批注。你可以移动、调整大小、添加标题，把它放在对应实验步骤旁边。

**图片批注是当时的快照。** 后续修改参数不会把已经贴出的图片替换掉；实时结果仍以节点里的预览为准。比较两次实验时，可以分别贴图并写清参数和结论。

### 6.5 在资产库里找来源

点击顶栏 **运行** 后，打开 **资产库** 查看本次资产汇总。点击某项可以查看图表、表规模、指标及来源节点等详情。

资产库适合快速找到本次结果，实验笔记和报告适合记录判断。要长期保留某张图，可以贴到画布或写入报告；不要把资产列表当作完整的实验归档。使用 **清空** 前，先保存需要的记录。

## 7. 子空间与常用模块

### 7.1 把一段实验收进子空间

当画布太长时，框选一组步骤和相关批注，点击 **组合为子空间**。它们会收进一个 **复合组块**，外层保留需要与其他步骤连接的接口。

- 双击组块，或选中后点击 **进入组块**，编辑内部画布。
- 使用上方路径返回父级或根画布；子空间可以继续嵌套。
- 选中外层组块，在右侧修改它已公开的参数，参数会传给对应的内部节点。
- 选中组块和批注，使用 **移入所选组块**，把图片、表格等放进对应实验。
- 使用 **展开组块**，将内部内容重新放回当前层。

子空间也可以只放批注，用来整理一组图片或实验想法。它提供的是收纳与分层，不会因此自动改变内部步骤的计算含义。

### 7.2 收藏常用节点

节点库卡片上的 `☆` 可以把节点钉到常用工具栏，再点 `★` 可移出。搜索框用于按关键词找到节点；各分类也可以折叠。

### 7.3 保存自己的函数模块

点击左侧 **＋ 新建模块**，填写名称、分类、说明和 Python 函数。下方端口预览会随代码变化，保存后模块出现在节点库中。

已有自建模块可以通过卡片上的编辑按钮修改，也可以删除。自建模块和收藏保存在当前浏览器的本地存储里；清理浏览器数据、换浏览器或换设备时，不应假定它们会自动同步。

**子空间** 用于整理一组步骤和批注；**自建模块** 用于复用一个 Python 函数。当前工程不会附带整份自建模块注册表，含自建类型的工程要求目标环境先注册对应模块，否则会提示类型未注册。

准备跨设备分享的演示工程时，可以优先用内置 **函数** 节点保存同样的代码，让接收方无需先建立自己的模块库。相关 Python 依赖仍需核对。

## 8. 批注、实验笔记与项目报告

### 8.1 画布上的图片、表格与思维图

从剪贴板复制图片后，在画布上粘贴；也可以点击 **粘贴图片**。如果浏览器不允许按钮读取剪贴板，使用 `Ctrl+V` / `Cmd+V`。

图片可以调整大小，并填写可换行的标题。左侧还提供两种记录工具：

- **表格：**填写表名、列名和单元格，增加或删除行列，适合记录几组参数和人工比较结果。
- **思维图：**编辑中心主题和分支，用 `Tab` 或添加按钮增加子分支。

这些是画布批注，没有计算端口。手工表格中的数字不会自动成为训练数据；计算数据仍通过数据源和函数进入工作流。

### 8.2 实验笔记：记录为什么

在右侧 **实验笔记** 中写 Markdown，使用 **编辑 / 预览** 切换。`##` 标题会进入大纲，可以点击标题跳到对应位置；图片可以直接粘贴进笔记。

选中画布上的块，点击 **@ 引用选中的块**，可以把节点引用插进笔记。预览中点击引用，会把画布聚焦到对应块，方便从文字回到实验步骤。

建议每次至少记下：

1. 这次想验证什么。
2. 改了哪些参数或数据划分。
3. 从哪个节点、指标或图得到判断。
4. 下一步准备检查什么。

笔记会随工程保存。浏览器里的草稿方便继续编辑，需要交接时仍应点击 **保存工程**。

### 8.3 项目报告：整理可交付的结果

点击顶栏或右侧 **项目报告**，打开浮动窗口。报告窗口可以拖动、调整大小、最小化或最大化，方便对照画布。

可以 **新建** 报告，切换 **编辑 / 预览**，修改标题和 Markdown 正文，点击 **保存修改**。内置 Agent 生成的项目报告也在这里查看。

**下载 MD** 可导出所选报告；先保存编辑内容，再下载。报告中的已嵌入图片会随报告保留，不必另外寻找当时的截图。

报告写入了工程，还是只留在本机草稿中，以保存提示为准。如果顶栏出现 **允许写回**，点击它并授权，或使用 **保存工程** 导出一份文件。

如果提示 Agent 或其他窗口更新了同一份报告，先核对新版，再决定怎样合并自己的修改；当前未保存的编辑不会直接覆盖新版。

## 9. 模型、训练与评估

这一部分需要 [启动本地宿主](../README.md#本地宿主训练与内置-agent)。先确认顶栏已连接宿主，再添加模型和训练节点。

### 9.1 先准备接口，再开始训练

常见流程是：

```text
数据源 → 处理 / 划分函数 → 训练集、验证集、测试集
自定义模型 + 训练集（及可选验证集） → 自定义训练
已训练模型 + 测试集 → 模型预测 → 评估打分
```

**自定义模型** 定义模型结构。通过 `MODEL_PARAMS` 或支持的构造函数参数声明，界面可以生成模型基础参数控件；列表参数可以在控件中增加、删除和修改元素。

**自定义训练** 提供训练函数，训练轮数、批大小和算法应与该函数的接口对应。先查看节点自带模板与端口说明，再接入模型和数据。模型结构参数与训练参数是两个不同位置，修改时先确认你要控制哪一项。

数据划分和预处理由实验流程负责。检查标签列、特征列、训练与测试的分离，以及评估时是否复用训练阶段的变换；当前版本不会自动证明这些研究条件全部正确。

### 9.2 查看进度，停止和重新训练

自定义训练接好线后，点击节点上的 **开始训练**。它不会因为你刚刚改了一个参数就自动开始占用 GPU。

训练时可以看节点进度、消息和曲线。曲线缩略图帮助观察走势；具体数值看指标或曲线表，不能仅凭缩略图高度比较不同指标。

点击 **停止训练** 后，需要等待训练函数到达可响应停止的检查点。“停止中”表示请求已发出，不代表 Python 已经立即退出。停止后的本次模型和曲线不会作为完整训练结果保留；已经保存的旧制品仍保留。

训练完成后可以 **重新训练**。修改参数后再训练，会生成新的模型版本；节点会标明当前制品和历史或已过期制品。看到 **已加载/已训练** 时，可能是从已有制品加载，并没有重新跑一次训练。

### 9.3 用预测和指标检查结果

把已训练模型接到 **模型预测**，同时接入要预测的数据；需要标准化器的流程还应接入对应变换。将预测表接到 **评估打分**，并核对真实值与预测值的字段映射。

评估结果可以接 **数据预览** 查看数值，也可以把曲线和结果图贴回画布。保存工程时一并保留模型制品引用；分享权重的说明见 [保存与分享](#files)。

## 10. 让 Agent 协助做实验

### 10.1 先配置自己的模型服务

启动宿主后，进入 **AI 工作区 → 模型服务设置**：

1. 选择服务商，或选择自定义兼容服务。
2. 填写 API key、基础地址和需要的模型 ID，保存配置。
3. 在对话区选择模型；使用支持工具调用的模型。

目前有 DeepSeek、OpenAI、Gemini 兼容入口、通义千问、Moonshot、OpenRouter、OpenCode Go 及自定义兼容服务。各服务具体协议与设置见 [README 的 BYOK 说明](../README.md#byok使用自己的模型服务)。出现在模型列表里不等于一定支持工具调用或图片输入。

密钥输入会遮住，保存后清空，已有密钥不会回填。留空表示保留；删除需要点击 **移除本地配置**。如果宿主配置了对应环境变量，它会优先于界面保存值。

密钥保存在本机状态目录中，不进入 `.sciviz` 工程。这是本地明文配置文件，不是加密保险库；分享工程时不要附带 `.sciviz-state/`，也不要把 API key 写进对话、节点代码或报告。

### 10.2 选择改动权限和上下文范围

输入区有三档改动权限：

| 档位 | 现行行为 |
|---|---|
| 请求批准 | 每次写入前确认；运行结果行值外发也每次确认 |
| 帮我批准 | 普通图改动和工作区内 Markdown 写入直接执行；破坏性图改动与源码写入确认。行值外发需要授权 |
| 完全访问权限 | 默认档位。图改动、工作区内 Markdown 写入和运行结果行值读取直接执行；源码写入拒绝，工作区之外的路径仍不能访问 |

另有 **允许读取全部块内代码** 开关，当前默认开启：Agent 可以按需读取当前工程的块内代码。关闭后撤销这项读取权限。

**允许读取运行结果行值** 决定模型能否取得实际数据值。在“完全访问权限”档下默认允许且不能单独关闭；需要逐次确认时，切换到“请求批准”。使用其他档位时可查看、授予或撤销这项授权。

连接远程模型时，被读取的代码、行值、对话和附件会发送到所选服务商。先选择符合本次实验需要的档位，再发送任务。

### 10.3 把“这个块”明确交给 Agent

输入 `@`，从列表选择节点；子空间内部的节点也可以引用。引用会携带节点身份，减少只说“左边那个函数”带来的歧义。

也可以先在画布选中节点，复制后粘贴到 Agent 输入区，作为块附件交给它查看。

AI 工作区支持添加、拖入或粘贴图片和 PDF：最多 10 个文件，单文件不超过 20 MiB。附件先在本机读取，再用于所选模型的请求；PDF 的解析内容与图片能力仍受模型支持范围影响。

例如，先引用自己的处理函数，再发送：

> 请检查这个函数的输入输出和工作段参数，把输出接一个数据预览。先说明准备改哪里，完成后给出本次读取的数值，并写一份简短项目报告。

用 `Enter` 发送，`Shift+Enter` 换行。Agent 发出选择问题时，在问题卡片中选择或填写答案，再继续任务。

### 10.4 边做边看，再人工接手

对话会显示任务进度、工具操作及返回结果。Agent 改图后，可以切回 **画布** 查看参数、接口和实际预览；需要长期记录时，让它生成项目报告，再到报告窗口核对。

**独立窗口** 可以把 Agent 对话移到单独窗口，让主窗口保持画布视野。点击 **回到主窗口** 可以收回；独立窗口与主界面使用同一份对话状态。

点击对话中的 **停止** 可中止当前对话任务。停止不会撤销已经应用的工程改动，也不能代替所有运行任务的停止按钮；训练仍要检查训练节点状态。需要回退画布修改时，查看实际改动后使用撤回。

人工接手时，先核对当前参数、上游输出和正在运行的节点，再修改同一条链路。成功的工具提示只说明对应操作完成，实验结论仍需要看数值和图。

### 10.5 管理对话，用只读问答快速查阅

AI 工作区可以为同一项目建立多个对话，修改对话标题、归档、恢复或删除，并 **导出** 当前会话的 JSONL 记录。归档只是从活跃列表收起，对话仍可恢复。

对话记录保存在本地宿主中，工程文件不会自动携带整段对话历史。JSONL 可能包含工程上下文和工具结果，分享前检查内容。

只想问“这个节点接了什么”“这里的参数是什么意思”，打开画布右侧 **只读问答**。它有独立的问答会话，不修改或运行工程；需要执行任务时使用 **AI 工作区**。

## 11. 保存、重开与分享工程

### 11.1 优先保存完整工程

点击 **保存工程**，得到 `.sciviz` 文件。它是可阅读的文本工程，保存工作流、参数与代码、数据引用、子空间、批注、实验笔记、项目报告和模型制品引用等内容。

Chrome / Edge 在获得文件写权限后，可以把修改自动写回已打开的工程文件。出现 **允许写回** 时，需要点击授权；出现 **有未保存的修改 · 保存** 时，先保存再离开页面。

不支持直接写回的浏览器会下载文件。此时请自己管理下载版本；本机草稿与“已经存到工程文件”不是同一个状态。

### 11.2 打开后核对数据与模型

`.sciviz` 不会内嵌 CSV 原文或模型权重。重新打开时，如果当前工作区没有相应数据，需要重新导入并核对数据源绑定；模型制品也需要在宿主中实际存在。

本地文件被其他工具或 Agent 修改时，页面会在重新获得焦点时检查。有冲突会提示 **文件被改过了 · 重新载入**；先保存或处理自己尚未落盘的修改，再决定是否载入磁盘版本。

### 11.3 YAML 用于交换工作流

顶栏 **导出 YAML** 可以复制或下载工作流文本。**导入 YAML** 会覆盖当前工作流，导入前先保存当前工程，并阅读导入后的告警。

YAML 入口用于工作流图的交换。要连同笔记、图片批注和报告等项目内容交接，使用 **保存工程** 生成的 `.sciviz`。

### 11.4 交给别人时带齐哪些东西

| 内容 | 怎样交接 |
|---|---|
| 工作流、参数、代码、笔记与报告 | 保存 `.sciviz` |
| CSV 等原始数据 | 另附数据文件，说明数据源对应关系 |
| 训练得到的模型 | 另附需要的权重或制品，说明引用和执行环境 |
| Python 依赖、随机种子、数据划分 | 写入报告或附带环境与配置说明 |
| 自建模块 | 目标环境先注册对应类型；演示工程可优先使用内置函数节点 |
| 对话过程 | 按需导出 JSONL，检查后再分享 |
| API key | 由接收方自行配置，不放入交接文件 |

建议先用合成数据或可公开数据准备演示工程，让接收方先跑通一个小例子。正式实验再核对数据版本、预处理和执行环境。

## 12. 常见问题与小功能速查

### 12.1 遇到问题先检查什么

| 现象 | 先检查 |
|---|---|
| 导入成功，节点仍没有数据 | 数据源是否选择了该数据集，所需列是否启用 |
| 拆列没有出现预期端口 | 上游是否已经计算，索引是否从 1 开始且排除了时间列 |
| 连线被拒绝 | 读界面给出的原因，核对类型、单输入占用和循环连接 |
| 图表空白 | 是否接入实际数据表，上游有无报错，X / Y 是否对应现有列 |
| 改参数后图片没变 | 看的是节点实时预览，还是已经贴到画布的快照 |
| 画布太拥挤或找不到节点 | 切换紧凑显示、适应视野，或用子空间分层 |
| 浏览器引擎一直加载失败 | 确认已同步 Pyodide 文件，查看页面错误提示；本机下载器或网络过滤也可能影响资源加载，反馈时附上加载错误 |
| 训练按钮不可用 | 本地宿主是否启动并连接，模型和训练数据是否接好 |
| 停止后仍显示“停止中” | 等待训练函数检查点，检查该函数是否响应停止 |
| Agent 提示未配置或发送不可用 | 宿主是否在线，服务配置是否保存，是否选择了合适的模型 |
| 模型列出来了，但工具调用失败 | 该模型及账户是否支持所需工具调用协议；需要看实际返回错误 |
| 报告只存在草稿中 | 顶栏是否需要“允许写回”，是否已经保存工程 |
| 换设备后数据或模型不可用 | 相关 CSV、权重和执行环境是否一起交接 |
| 打开工程提示节点类型未注册 | 是否用了当前浏览器里才有的自建模块，目标环境是否已注册对应类型 |

### 12.2 容易忽略的小功能

| 想做的事 | 功能入口 |
|---|---|
| 快速找出一个节点的整条上下游 | 点击计算节点，查看突出显示的链路 |
| 减少参数口造成的拥挤 | 可选参数的“收起接线口” |
| 给英文参数补中文解释 | 右侧参数旁的中文说明 |
| 确认处理步骤的真实数值 | 插入“数据预览” |
| 保留参数修改前后的两张图 | 分别“贴到画布”，填写图片标题 |
| 给常用节点留一个快捷入口 | 节点库卡片上的 `☆` |
| 把图与实验步骤放在一起 | 框选后“组合为子空间”，或“移入所选组块” |
| 从笔记跳回实验步骤 | “@ 引用选中的块”及预览中的节点引用 |
| 一边看报告一边改画布 | 项目报告浮动窗口 |
| 一边看 Agent 操作一边检查接口 | AI 对话“独立窗口” |
| 让 Agent 明确知道要处理哪一步 | 输入 `@` 或复制块到对话输入区 |
| 只提问，不触发工程操作 | 画布右侧“只读问答” |
| 保存整个项目以便继续 | 顶栏“保存工程” |

提交问题时，尽量附上操作步骤、预期与实际结果、浏览器及宿主环境。能用小型合成数据重现的问题，最方便排查；提供截图或工程前，检查其中是否含有需要保留的个人数据与凭据。
