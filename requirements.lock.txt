# 生成方式（注意不是 pip freeze，见 docs/开发日志.md：仓库路径含中文时它会在解析
# 可编辑安装的路径上崩掉）：
#   .\.venv\Scripts\python.exe -m pip list --format=freeze > requirements.lock.txt
# 再把 sciviz-host==x.y.z 那一行换成 -e ./sciviz-local。
#
# 用途与边界：
# - requirements.txt 是「要什么」（人改），本文件是「上次装出来的是什么」（生成）。
# - torch / torchvision 带 +cu126 后缀，只在 PyTorch 自己的索引上，PyPI 没有。
#   所以直接 `pip install -r requirements.lock.txt` 会找不到 —— 用
#   .\setup-env.ps1 -Locked，它会带上 PyTorch 索引。
# - 换机器复现同一份环境用 -Locked；日常加库改 requirements.txt 再 -Update。
